# Diagram Sources

## Purpose

This folder contains editable PlantUML source files for the main diagrams used to explain the security monitoring system.

## Files

- `class-diagram.puml`: major application modules and their relationships.
- `request-statechart.puml`: request monitoring and analysis lifecycle.
- `security-analysis-flow.puml`: baseline security analysis and LLM fallback flow.

## Rendered Diagrams

Rendered images or PDFs can be generated from these source files for the final zipped submission package. The source files remain in the repository so the diagrams can be edited as the implementation changes.
